               Created by Jeel Vaghani • OSLC HOUSE

આ સોફ્ટવેર ઑફિસ/ફેક્ટરીના બીજા કોઈપણ લેપટોપ કે પીસીમાં ચલાવવા માટે:

૧. કોઈપણ સોફ્ટવેર કે Node.js ઇન્સ્ટોલ કરવાની જરૂર નથી.
૨. ફક્ત ખાતરી કરો કે તમારું PC અને મુખ્ય PC (PC-106) એક જ Wi-Fi કે LAN નેટવર્ક સાથે જોડાયેલા છે.
૩. આ ફોલ્ડરમાંથી "OSLC_PC.exe" અથવા "START_OSLC_OFFICE.bat" ડબલ-ક્લિક કરીને ચાલુ કરો.
૪. એપ ડાયરેક્ટ ડેસ્કટોપ વિન્ડો મોડમાં ખુલી જશે.

જો કોઈ કારણસર લિંક ન પકડે તો બ્રાઉઝરમાં આ લિંક ખોલો:
http://192.168.100.106:5173/
