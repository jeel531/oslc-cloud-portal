   OM SAI LATEST CREATION - ૨૪ કલાક ફ્રી માં લાઈવ (CLOUD HOSTING) કરવાની ગાઈડ
========================================================================================

આ પ્રોજેક્ટ (OSLC Cloud Master Portal) માં તમારા ૪ મુખ્ય વેબ ડેશબોર્ડ્સ ભેગા થઈ ગયા છે:
  1. 📦 OSLC In / Out Report (/godaun)
  2. 📊 OSLC Stock Warehouse Report (/stock)
  3. ✂️ OSLC Karigar Alter Report (/alter)
  4. 📋 OSLC PO & Cutting Dashboard (/po)

========================================================================================
   રીત ૧: ઇન્ટરનેટ પર ૨૪ કલાક લાઈવ રાખવા માટે (PC બંધ હોય તોય ચાલુ રહેશે)
========================================================================================
ખર્ચ: ₹૦ (૧૦૦% મફત)

પગલું ૧:
  - https://github.com ખોલો અને તમારા એકાઉન્ટમાં લોગિન કરો.
  - "New Repository" પર ક્લિક કરો.
  - નામ આપો: oslc-cloud-portal
  - "Create repository" પર ક્લિક કરો.

પગલું ૨:
  - કમાન્ડ પ્રોમ્પ્ટ (CMD) માં નીચેના ૩ કમાન્ડ રન કરો:
      cd /d D:\OSLC_CLOUD_MASTER_PORTAL
      "C:\Users\PC-106\PortableGit-oslc-20260922094043\bin\git.exe" remote add origin https://github.com/YOUR_USERNAME/oslc-cloud-portal.git
      "C:\Users\PC-106\PortableGit-oslc-20260922094043\bin\git.exe" push -u origin master

પગલું ૩:
  - https://render.com ખોલો અને GitHub થી "Sign In" કરો (૧ ક્લિકમાં થઈ જશે).
  - "New +" -> "Web Service" ક્લિક કરો.
  - તમારી `oslc-cloud-portal` રિપોઝીટરી સિલેક્ટ કરો.
  - "Create Web Service" બટન દબાવો!
  
👉 બસ! Render તમારા પ્રોજેક્ટને લાઈવ કરી દેશે અને એક પબ્લિક લિંક આપશે:
   (દા.ત. https://oslc-master-portal.onrender.com)
   
આ લિંક તમારા WhatsApp ગ્રુપમાં મૂકી દેશો એટલે દુનિયાના કોઈપણ ખૂણેથી, મોબાઈલ કે કમ્પ્યુટરમાં
તમારું PC બંધ હશે તો પણ ૨૪ કલાક ચાલશે!

========================================================================================
   રીત ૨: તમારા PC માં કોડ ખોલ્યા વગર બેકગ્રાઉન્ડમાં ઓટોમેટિક ચલાવવા માટે
========================================================================================
જો તમે તમારા ઓફિસના વાઈફાઈ પર ચલાવવા માંગતા હોવ:
  - D:\OSLC_CLOUD_MASTER_PORTAL\AUTO_START_WITH_WINDOWS.bat ફાઈલ પર ડબલ ક્લિક કરો.
  - આ સેટ કર્યા પછી જ્યારે પણ તમારું કમ્પ્યુટર ચાલુ થશે, આ પોર્ટલ બેકગ્રાઉન્ડમાં
    છૂપી રીતે (સાયલન્ટ) ચાલુ થઈ જશે. તમારે ક્યારેય VS Code કે કોઈ કાળી વિન્ડો
    ખોલીને રાખવી નહીં પડે!
